📖 Sobre o Projeto

Este projeto é um layout de site inspirado no design do Starbucks, criado como um exercício para praticar e consolidar conhecimentos em HTML, CSS, CSS Grid e Flexbox. O design original foi baseado em um modelo do Nicepage, adaptado para implementar técnicas modernas de layout responsivo e estilização, com foco em:


Layouts responsivos com CSS Grid para seções de duas colunas e Flexbox para cabeçalho e alinhamentos. Adaptação para diferentes tamanhos de tela (desktop, tablet e mobile).


Boas práticas de organização de arquivos e versionamento com Git.


🛠️ Tecnologias Utilizadas


HTML5: Estrutura semântica do site.


CSS3: Estilização, incluindo CSS Grid, Flexbox e media queries.


Google Fonts: Fontes Open Sans e Oswald para tipografia.


Git/GitHub: Versionamento e hospedagem no GitHub Pages.


Este foi um projeto de aprendizado prática, para demonstração de habilidades em desenvolvimento front-end.
